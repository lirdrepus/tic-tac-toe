README

Numerical Tic Tac Toe is a variation of the classic Tic Tac Toe game.
Instead of X and O, players place numbers on the board achieve a winning sum across a row, column, or diagonal.

Two modes: Human vs Human Mode, Human vs Computer Mode
Player 1 input odd numbers and Player 2 (or the computer) input even numbers.
Enter an integer n for the board size n x n. 
Winning sum is calculated as n * (n * n + 1) / 2

Players take turns placing their assigned numbers into empty cells on the board.
Player 1 always starts first with an odd number.
A number can only be used once.
After each move, the board is updated and displayed.

A player wins if the sum of numbers in any row, column, or diagonal equals winning number.
If all cells are filled and no player achieves the winning sum, draw game.

Happy playing!
